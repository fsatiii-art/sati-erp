أضيفت:
- Asset Categories.
- Fixed Asset Register.
- Acquisition Cost / Residual Value / Useful Life.
- Straight-Line Depreciation.
- Depreciation Register وNet Book Value.
- Asset Transfers بين المواقع والعهد.
- Asset Revaluation.
- Asset Disposal: Sale / Scrap / Write-off / Donation.
- Gain/Loss on Disposal.
- Asset Tags وSerial Numbers.
- QR foundation عبر Asset Tag / QR base setting.
- Maintenance linkage foundation.
- Asset GL mapping foundation.
- Fixed Asset Summary Reports.
- Enterprise Audit Trail integration.

- QR foundation جاهز للربط بطباعة الملصقات، لكنه لا يولد ملصقات فعلية في هذا الإصدار.
- يجب مراجعة سياسة الإهلاك المحاسبية والضريبية للشركة قبل الاستخدام الإنتاجي.
